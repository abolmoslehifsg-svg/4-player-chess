# شطرنج ۴ نفره · ۲v۲ (4-Player Chess)

## ساختار صفحه اصلی

- **۲v۲ (اصلی)** — کارت بزرگ بالای صفحه
- **آنلاین** — روی صفحه اصلی می‌ماند (چون اتاق‌های ۲v۲ دارد)
- **بخش ۱v۱** — شامل:
  - شطرنج ۱v۱ کلاسیک
  - حالت نفوذی (هر مهره به‌جز شاه و وزیر · کنترل مشترک)
  - بازی با ربات‌ها
- **ابزار و پازل** — پازل‌ها و ارسال پازل

## قانون حالت نفوذی

- یک گیم‌مود جدا (داخل ۲v۲ نیست)
- در شروع، یک مهره تصادفی از هر طرف (به‌جز شاه و وزیر) به عنوان «نفوذی» انتخاب می‌شود
- هر بازیکن در نوبت خودش می‌تواند مهره نفوذی حریف را هم حرکت دهد
- اگر سرباز نفوذی به خانه آخر برسد و ارتقا یابد، مهرهٔ جدید مال **صاحب اصلی** آن نفوذی است
