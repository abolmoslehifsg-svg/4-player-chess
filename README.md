# شطرنج ۴ نفره · ۲v۲ (4-Player Chess)

یک بازی شطرنج وب کامل با حالت‌های:

- **۲v۲ روی تخته ۱۶×۸** با قانون **Guardian** (وقتی شاه یکی مات شود، بازیکن حذف نمی‌شود و مهره‌هایش در حالت Guardian باقی می‌مانند)
- **۱v۱ کلاسیک** با پشتیبانی Stockfish
- بازی آنلاین (PeerJS)
- پازل‌های تاکتیکی
- ویرایشگر موقعیت
- تم‌های مختلف، پروفایل محلی، تنظیمات

## نحوه اجرا

فقط فایل‌ها را روی یک سرور استاتیک باز کنید:

```bash
npx serve .
# یا
python -m http.server 8080
```

سپس مرورگر را روی آدرس سرور باز کنید.

> **نکته:** `index.html` فعلی یک loader هوشمند است که نسخه کامل و پایدار را از کامیت خوب می‌کشد و `mobile-fix.css` محلی را اضافه می‌کند. این موقت است تا نسخه کامل روی `main` commit شود.

## ساختار فایل‌ها

| فایل | توضیح |
|------|--------|
| `index.html` | رابط کاربری اصلی |
| `styles.css` | تم‌ها و استایل |
| `mobile-fix.css` | اصلاحات موبایل برای تخته ۱۶×۸ |
| `engine.js` | منطق خالص بازی ۴ نفره + AI (minimax + alpha-beta) |
| `ai-worker.js` | Web Worker برای جستجوی AI |
| `game-4p.js` | UI حالت ۲v۲ |
| `game-1v1.js` | UI حالت ۱v۱ + Stockfish |
| `online.js` | اتاق‌های آنلاین |
| `puzzles.js` | پازل‌ها |
| `ui-settings.js` | تنظیمات، تم، پروفایل، i18n |

## قانون Guardian

- تیم آبی: A و B
- تیم قرمز: C و D
- یک تیم فقط وقتی می‌بازد که **هر دو شاه** آن مات شده باشند.
- وقتی شاه یک بازیکن مات می‌شود → حالت Guardian: مهره‌ها باقی می‌مانند.
