# شطرنج ۴ نفره · ۲v۲ (4-Player Chess)

## ساختار صفحه اصلی

- **۲v۲ (اصلی)** — کارت بزرگ بالای صفحه
- **آنلاین** — روی صفحه اصلی (چون اتاق‌های ۲v۲ دارد)
- **بخش ۱v۱** — شامل:
  - شطرنج ۱v۱ کلاسیک
  - حالت نفوذی (هر مهره به‌جز شاه و وزیر · کنترل مشترک)
  - بازی با ربات‌ها
- **ابزار و پازل** — پازل‌ها و ارسال پازل

## قانون Guardian (۲v۲)

- تیم آبی: A و B | تیم قرمز: C و D
- یک تیم فقط وقتی می‌بازد که **هر دو شاه** آن مات شده باشند.
- وقتی شاه یک بازیکن مات می‌شود → حالت Guardian: مهره‌ها باقی می‌مانند.

## قانون حالت نفوذی (گیم‌مود جدید)

- یک مود جدا روی تخته ۸×۸
- در شروع، یک مهره تصادفی از هر طرف (**به‌جز شاه و وزیر**) به عنوان «نفوذی» انتخاب می‌شود
- هر بازیکن در نوبت خودش می‌تواند مهره نفوذی حریف را هم حرکت دهد
- اگر سرباز نفوذی به خانه آخر برسد و ارتقا یابد، مهرهٔ جدید مال **صاحب اصلی** آن نفوذی است
- در این مود AI از minimax داخلی استفاده می‌کند (نه Stockfish)

## نحوه اجرا

